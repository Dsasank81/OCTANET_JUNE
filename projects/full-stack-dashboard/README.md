# Full-Stack Dashboard

A compact Flask + SQLite task dashboard with HTML UI and a JSON read endpoint.

## Run
`python -m pip install flask`
`python app.py`
Visit http://127.0.0.1:5001. Tasks persist in a local `dashboard.db` file.

This is a starter implementation. Add authentication, CSRF protection, migrations, validation, pagination and production deployment controls before exposing it to the internet.
